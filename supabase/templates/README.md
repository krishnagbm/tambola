# DabHousie Supabase Email Templates

This directory stores the official HTML templates for automated Supabase Auth emails.

---

## 1. Where to Find & Configure in Supabase

1. Open your **Supabase Dashboard**:  
   [https://supabase.com/dashboard/project/itfcnurjrnyalauwwdkj/auth/templates](https://supabase.com/dashboard/project/itfcnurjrnyalauwwdkj/auth/templates)
2. In the left navigation, go to **Authentication** &rarr; **Email Templates**.

---

## 2. Templates to Update

Because DabHousie uses 6-digit OTP verification via `_supabase.auth.signInWithOtp(email, shouldCreateUser: true)`:
- **New Users** trigger the **Confirm signup** template (currently titled with subject `DabHousie Registration token`).
- **Returning / Existing Users** trigger the **Magic Link** template.

Both templates should be updated with the unified template below so all users receive the same high-contrast, branded experience.

---

### A. "Confirm signup" Template

- **Subject Line:**
  ```text
  {{ .Token }} is your DabHousie sign-in code
  ```
  *(Alternative: `Your DabHousie Sign-In Code: {{ .Token }}`)*

- **Message Body (HTML):**
  Copy & paste the contents of [`email_otp_template.html`](./email_otp_template.html).

---

### B. "Magic Link" Template

- **Subject Line:**
  ```text
  {{ .Token }} is your DabHousie sign-in code
  ```

- **Message Body (HTML):**
  Copy & paste the contents of [`email_otp_template.html`](./email_otp_template.html).

---

## 3. Template Variables Used

- `{{ .Token }}`: The 6-digit OTP verification code generated by Supabase Auth (e.g., `498331`).
- `https://www.dabhousie.com/dabhousie_horizontal_logo.png`: Official production logo.
- `contact@dabhousie.com`: Official support and compliance email.
