Flutter
-------

Keep the transparent PNG originals in assets/branding/ if you want to use the
logo/monogram inside the application UI.

Important
---------
The generated artwork contains the current visual treatment and wording exactly
as represented in the supplied identity sheet. Before commercial trademark
filing, final artwork should be reviewed by a trademark professional/designer.
