# Backend Terminology & Confidentiality

- **Do NOT disclose backend tool specifics** (such as `Supabase`, specific database providers, internal RPC names, or infrastructure vendors) in user-facing or external materials.
- This applies to:
  - Video scripts and voice narrations
  - On-screen celebration cards, banners, and overlays
  - Public marketing copy, documentation, and demo text
  - Client-facing UI labels, error messages, and toasts
- **Use generic cloud terminology** instead:
  - Use terms like *"Cloud"*, *"Secure Cloud Sync"*, *"Real-Time Cloud Verification"*, *"Cloud Engine"*, or *"DabHousie Cloud"*.
  - Example: Replace *"verified on Supabase Cloud"* with *"verified in the cloud"* or *"real-time cloud verification"*.
